## Learning Objectives

By the end of this week, students will be able to:
1. Understand data mining principles and techniques
2. Evaluate quality and suitability of secondary data sources
3. Identify appropriate data sources for research questions
4. Assess data availability and accessibility
5. Consider data limitations and biases
