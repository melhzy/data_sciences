## Weekly Topic

Survey design, qualitative research methods, content analysis, and data labeling techniques for primary data collection.

## Learning Objectives

By the end of this week, students will be able to:
1. Design effective surveys for data collection
2. Understand qualitative research methods
3. Conduct basic content analysis
4. Develop data labeling schemes
5. Recognize when primary data collection is appropriate

## Key Concepts

- Survey question design
- Sampling strategies
- Interview techniques
- Content analysis methodologies
- Data labeling and annotation
- Interrater reliability
- Qualitative vs. quantitative data

## Key Deliverables

- Understanding of primary data collection methods
- Practice with content analysis
- Assessment of whether primary data collection is needed for capstone
