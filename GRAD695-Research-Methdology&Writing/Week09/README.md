Prompt engineering as experimental design for AI/LLM-based research projects.

### Comparing Prompts (In-Class Exercise)
- **Points:** 25 points

## Learning Objectives

By the end of this week, students will be able to:
1. Understand prompt engineering principles
2. Design effective prompts for LLMs
3. Treat prompt design as experimental manipulation
4. Evaluate prompt effectiveness systematically
5. Document prompt engineering methodology

## Key Concepts

- Prompt design strategies
- Zero-shot vs. few-shot learning
- Chain-of-thought prompting
- Prompt parameters and temperature
- Systematic prompt evaluation
- Reproducibility in LLM research
- Ethical considerations in AI research

## Key Deliverables

- Understanding of prompt engineering methodology
- Comparative analysis of prompt strategies
- Application to capstone project (if relevant)
