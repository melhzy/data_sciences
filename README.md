# Data Sciences — Teaching & Tutorial Repository

[![GitHub Pages](https://img.shields.io/badge/Live%20Portal-GitHub%20Pages-blue?style=flat&logo=github)](https://melhzy.github.io/data_sciences/)

This repository contains teaching materials, tutorials, and applied projects for analytics and data science courses at Harrisburg University.

**📊 Live Course Portal:** [https://melhzy.github.io/data_sciences/](https://melhzy.github.io/data_sciences/)

## Courses

### 📊 ANLY 500 — Analytics I: Principles & Applications

Comprehensive R programming instruction for data analytics, covering foundational concepts through advanced statistical modeling and visualization. Code-first, theory-grounded tutorials with IEEE-style citations from Field et al. (2012).

- [View Course Materials](./ANLY500-Analytics-I/) · [Live Tutorials](https://melhzy.github.io/data_sciences/#500)

| Week | Topic |
|------|-------|
| 01 | Introduction to R |
| 02 | R for Data Analytics |
| 03 | Data Wrangling & EDA |
| 04 | Statistical Inference |
| 05 | Data Visualization |
| 06 | Data Screening Part 1 |
| 07 | Data Screening Part 2 |
| 08 | Correlation Analysis |
| 09 | Linear Regression |
| 10 | Mediation & Moderation |
| 11 | Comparing Two Means |
| 12 | Comparing Several Means (ANOVA) |

### 🤖 ANLY 530 — Machine Learning

Theory and practice of machine learning using Python with Scikit-Learn, Keras, and TensorFlow. Topics progress from classical supervised and unsupervised learning through deep neural networks.

- [View Course Materials](./ANLY530-Machine-Learning/) · [Live Tutorials](https://melhzy.github.io/data_sciences/#530)

| Week | Topic |
|------|-------|
| 01 | Introduction to Machine Learning |
| 02 | Decision Trees |
| 03 | Ensemble Learning & Random Forests |
| 04 | Regression Models |
| 05 | Support Vector Machines |
