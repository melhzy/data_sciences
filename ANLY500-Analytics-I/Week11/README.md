# Week 11: Comparing Two Means (The t-test)

This week focuses on comparing two means using the **t-test**. We cover the theoretical underpinnings (Signal-to-Noise Ratio) and practical application in R.

## Tutorials

-   **[R for Data Analytics](11_R_for_DataAnalytics.html)**: A comprehensive guide to independent and dependent t-tests, assumption checking (Normality, Homogeneity), effect sizes (Cohen's d, Pearson's r), and visualization (Boxplots, Slope Graphs).
-   **[Lecture Slides](11_ttests.html)**: The slide deck for the lecture, covering the statistical theory and logic behind the t-test.

## Key Concepts

-   **Signal-to-Noise Ratio**: $t = \frac{\text{Signal}}{\text{Noise}}$
-   **Assumptions**: Normality (Shapiro-Wilk) and Homogeneity of Variance (Levene's Test).
-   **Effect Sizes**: Understanding the magnitude of the difference using Cohen's $d$.
